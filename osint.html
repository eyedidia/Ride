1 פרופיל ציבורי — מה שכל אחד רואה

פתח את הפרופיל כאורח — כך רואה אותו מי שאינו מחובר לאינסטגרם. Picuki ו-Imginn הם מראות ציבוריות שלא דורשות כניסה.

📸 פתח פרופיל ב-Instagram הצגה כאורח (ייתכן שידרוש כניסה) 🔓 פתח ב-Picuki מראה ציבורית — ללא כניסה לאינסטגרם 🔓 פתח ב-Imginn מראה ציבורית — ללא כניסה לאינסטגרם
2 ארכיון ישן — WayBack Machine

בדוק אם יש צילומי מסך ישנים של הפרופיל — כולל פוסטים שנמחקו, ביוגרפיה ישנה, ושמות משתמש קודמים.

🕒 פתח ב-WayBack Machine ארכיון אינטרנט — כל מה שנשמר לאורך השנים
3 עקבות ב-Google

חיפושים ממוקדים ב-Google — מה שנסרק ונשמר. כל חיפוש נפתח בלשונית חדשה.

4 אותו שם משתמש בפלטפורמות אחרות

אם השתמשת באותו username בפלטפורמות אחרות — ניתן למצוא אותך שם גם כן. Sherlock בודק 300+ אתרים.

Sherlock — חיפוש Username (ללא session)
python3 sherlock can_not_anymore
הוראות התקנה
git clone https://github.com/sherlock-project/sherlock.git cd sherlock pip install -r requirements.txt
Social-Analyzer — חיפוש על 1000+ פלטפורמות
node app.js --username "can_not_anymore" --mode fast
הוראות התקנה
git clone https://github.com/qeeqbox/social-analyzer.git cd social-analyzer npm install

✅ מה המסקנה?

מייל וטלפון לא נחשפים לזרים אנונימיים.
מה שכן נגיש: שם, ביו, תמונה, פוסטים, ועקבות ישנות ב-Google ו-WayBack Machine.

הסיכון האמיתי הוא אם אתה משתמש באותו username במקומות אחרים ברשת — ניתן לחבר בין הזהויות.
